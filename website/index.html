DockBridge

A native macOS SFTP client with a two-pane file browser, saved connections, transfer queue, and Keychain-backed credentials.

Features

Two-pane browser

Navigate local and remote directories side by side, WinSCP-style.

SFTP transfers

Upload, download, delete, rename, and create directories over SFTP.

Saved connections

Store connection profiles with passwords and passphrases in Keychain.

Host key verification

Review SHA-256 fingerprints before trusting a server on first connect.

Requirements

  • macOS 15 Sequoia or later
  • Apple Silicon or Intel Mac
  • Network access to your SFTP server

Install

かんたんインストール（推奨）

  1. Download the latest DockBridge-*-macOS.dmg from the button above.
  2. Double-click the DMG file to mount it.
  3. Double-click DockBridgeをインストール.command inside the DMG. If macOS blocks it, right-click the file and choose Open, then confirm.
  4. Wait for the setup script to finish. DockBridge opens automatically when done.

手動インストール

  1. Drag DockBridge.app into the Applications folder shortcut.
  2. Follow the Gatekeeper steps if macOS blocks the app.

Opening unsigned builds

Early releases are not yet signed with a Developer ID certificate. macOS may show a warning that the developer cannot be verified.

The easiest fix is to run DockBridgeをインストール.command from the DMG. It installs DockBridge, removes the security block, and launches the app for you.

If you installed manually:

  • Right-click DockBridge.app and choose Open, then confirm.

Developer ID signing and Apple Notarization are planned for v1.0. See the security docs.
