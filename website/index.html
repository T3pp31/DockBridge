DockBridge

A native macOS SFTP client with a two-pane file browser, saved connections, transfer queue, and Keychain-backed credentials.

Features

Two-pane browser

Navigate local and remote directories side by side, WinSCP-style.

SFTP transfers

Upload, download, delete, rename, and create directories over SFTP.

Saved connections

Store connection profiles with passwords and passphrases in Keychain.

Host key verification

Review SHA-256 fingerprints before trusting a server on first connect.

Requirements

  • macOS 15 Sequoia or later
  • Apple Silicon or Intel Mac
  • Network access to your SFTP server

Install

  1. Download the latest DockBridge-*-macOS.dmg from the button above.
  2. Double-click the DMG file to mount it.
  3. Drag DockBridge.app into the Applications folder shortcut.
  4. Open DockBridge from Applications. Because releases are not yet Developer ID signed, macOS may block the first launch — right-click the app, choose Open, then confirm. You can also allow it under System Settings → Privacy & Security.
